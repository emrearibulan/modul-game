# Reference Games

These references guide lessons, not cloning. The North Star remains authoritative.

## Pathogenic

- DESIGN — ChatGPT: Reference for visible physical progression and spatial component synergies.
- SHOULD COPY: Clear physical changes that alter capability and create spatial relationships.
- SHOULD NOT COPY: Fiction, full progression model, pacing, or any specific mechanic that does not serve spacecraft construction.
- Modul lesson: The player should be able to look at the ship and understand how new components changed both shape and strategy.

## Noita

- DESIGN — ChatGPT: Reference for systemic interaction and experimentation.
- SHOULD COPY: The excitement of combining simple parts into surprising outcomes.
- SHOULD NOT COPY: Full pixel simulation, uncontrolled material complexity, or chaotic readability costs.
- Modul lesson: Systemic interactions should be authored, testable, and readable enough that players can form hypotheses.

## Pinmoney

- DESIGN — ChatGPT: Reference for graphical polish.
- SHOULD COPY: Crisp feedback, pleasant tactility, and a finished visual surface.
- SHOULD NOT COPY: Gameplay structure, economy, progression, or interaction model.
- Modul lesson: Polish should make the spacecraft feel precise, physical, and satisfying to alter.

## Reference Discipline

- PO DECISION: References are advisory, not authority.
- DESIGN — ChatGPT: Each reference lesson must be translated into a Modul-specific rule before implementation.
- DEVELOPMENT — Codex: Implementation should follow approved Modul rules, not raw reference imitation.
- BLOCKED: Any feature justified only by "the reference game does it" is not ready.
